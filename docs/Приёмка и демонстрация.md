# Проверка интеграций

1. Подключите Google Sheets, ProxyAPI, Apps Script и Telegram.
2. Обработайте контрольную заявку и сверьте балл и рекомендацию.
3. Для горячего лида проверьте уведомление. Повторный запуск без изменений должен пройти без повторной отправки.
4. Проверьте, что сводка и очередь отражают записанные оценки.
